# Sorting Algorithms in C

## How to Test

To compile and run the project on **Linux/macOS**, open a terminal in the project directory and run:

```bash
make sorting_program
./sorting_program
```

On **Windows** using MinGW, run:

```bash
mingw32-make sorting_program
./sorting_program
```

After testing the project, clean up the generated object files (`.o`) and executable by running:

**Linux/macOS:**

```bash
make clean
```

**Windows:**

```bash
mingw32-make clean
```
